# Job Search Dashboard
### A focused search workspace for Azure Data Engineering roles

**Search settings · freshness filters · reusable search presets**

</div>

A lightweight, single-page dashboard that helps keep an Azure Data Engineer job search focused. Start with built-in keyword and date presets, tune the search criteria, and copy a ready-to-use search link.

## Features

- Search terms prefilled for Azure Data Engineer roles, including Azure, Databricks, PySpark, ADF, ADLS, SQL, and Python
- Adjustable experience range and India location defaults
- Freshness filters for the last 24 hours, 7 days, or 30 days
- Daily, catch-up, and Databricks-focused presets
- Copyable search link for use in your preferred job-search site
- Browser-local settings for a quick return to your search

## Run locally

No build tools or package installation are required. Clone or download the repository and open `index.html` in a modern browser.

## Built with

Vanilla **HTML, CSS, and JavaScript**. The project is a static client-side dashboard; it does not include a job listings backend or automatically apply to roles.

## Repository layout

- `index.html` — dashboard structure
- `styles.css` — layout and visual design
- `script.js` — presets, filters, and search-link behavior
- `logos/` — project branding assets
